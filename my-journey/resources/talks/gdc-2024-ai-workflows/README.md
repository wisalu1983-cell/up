# GDC 2024 — AI Workflows

This folder contains the source media and transcript for the GDC 2024 AI
workflows talk. It is kept as a self-contained learning reference under
`my-journey/resources/talks/`, separate from plans, diagnostics, and weekly
reviews.

- [`media/`](media/) — source video, extracted audio, and all transcripts
