# GDC 2024 — AI Workflows

This folder contains the source media and transcript for the GDC 2024 AI
workflows talk. It is kept as a self-contained learning reference under
`my-journey/resources/talks/`, separate from plans, diagnostics, and weekly
reviews.

## Contents

- [`media/`](media/) — source video, extracted audio, and all transcripts

## Files

- [Audio](media/gdc-2024-ai-workflows-baseline-1080p.m4a)
- [Readable transcript](media/gdc-2024-ai-workflows-baseline-1080p.md)
- [SRT subtitles](media/gdc-2024-ai-workflows-baseline-1080p.srt)

The Markdown transcript is grouped into longer reading paragraphs. The SRT
file keeps finer-grained timing for subtitle playback. Both are automatically
generated from the source audio and may contain occasional proper-name or
wording errors that should be checked against the recording.

The current repository stores the audio and transcripts listed above. A source
MP4 is not present in the current tree. The same media folder also contains ten
VOA Learning English HTML transcripts with timestamp links; see the
[training resource index](../../README.md) for playback and transcript caveats.
