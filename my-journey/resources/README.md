## 使用要求

真实原声先选择15～30秒且情境清楚的片段；VOA可用于较慢语流桥接，GDC用于专业现场适应。先选匹配目标和当前负荷的内容，再提取1～2条实际有用表达。教师重读须另标为朗读。

材料保存不等于学习完成。每次执行后把实际片段、播放条件及首听证据链接到sessions/。
