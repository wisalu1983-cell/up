## 2026-09-22｜GDC 自我介绍、NPC 记忆系统听力与跨场景迁移

### 训练概况

- 会话约从 09:25 持续到 10:27，中间有一次较长暂停，约 10:20 恢复。
- 有效训练时间无法精确还原；从实际轮次判断，大概率超过计划的 12～15 分钟。
- 单复数切换、`over the weekend`、项目句复测、第一轮 GDC 自我介绍、短听力、结构信号、延迟复测和跨场景迁移均有执行。
- 第二轮 GDC 自我介绍未执行。
- 实际听力材料为 41 词，未达到计划要求的 75～90 词。

流程有效性限制：

- 单复数切换过程中提前给出了 `Multiple agents live...` 和 `The agent decides...`，后续相关答案受到提示影响。
- 自我介绍缺少第二轮，无法观察纠正后的即时改善。
- 听力长度不足，不能作为 75～90 词目标能力的标准测试。
- 暂停恢复后教师重新概述了部分听力内容，恢复后的回答不能反向计入首听或二听成绩。
- 用户明确提出纠错要求：

> If you want me to fix something, you should tell me what’s wrong and where I should fix and how to fix it.

后续教师必须先指出具体错误位置、原因和正确表达，再要求用户重说。禁止只说 `Try again` 或反复要求重说而不说明问题。

### 任务说明不足的证据

本次对话中存在多次用户已经听到教师所说的词句，但不知道需要输出什么内容的情况。这类情况需要与英语听力困难分开记录。

#### multiple agents 任务

教师最初要求：

> Tell me about multiple agents.

用户询问：

> What exact you want to know about the multi agents?

教师随后才澄清：只需要用一个简单句描述多个 agents 住在哪里。原始要求缺少输出长度和内容范围。

#### one agent 决策任务

教师要求用户说一个 agent 如何作决定，但没有明确需要一个完整句，也没有说明需要描述哪一项信息。用户询问希望听到哪种句子并要求例子。教师直接给出：

> The agent decides what to do.

这既反映了任务说明不足，也造成测试答案提前泄露。

#### GDC 交通方案任务

教师先要求表达一个所有人都能接受的计划。用户随后澄清：

> I mean the context. I didn't hear the context well.

之后又询问：

> One sentence for what I don't understand.

教师重新说明 venue、步行、出租车和 shuttle 三种选择后，任务才变得具体。这里同时存在情境信息没有进入理解和输出要求不清两个因素，不能直接记为 `work for everyone` 提取失败。

判断原则：当用户询问 `What exactly do you want to know?`、`What sentence?`、`What target?`、`What should I say?` 或表示没有听懂 `context` 时，先将其标记为任务澄清请求。教师重新说明任务以后再开始记录语言表现。

### 单复数与第三人称单数复测

#### `The agent lives...`

第一次自然回答：

> The agent lives in a simulation town- can decide and act by themselves.

`agent lives` 无提示正确。后半句连接不完整，但不影响本项主谓一致判断。

#### `The agents live...`

澄清任务后的第一次回答：

> The multi agents living in uh… Simulation town, and they can um decide and act… By themselves.

主要问题：`agents living` 缺少有限谓语。随后获得完整纠正：

> Multiple agents live in a simulation town.

本项第一次自然回答失败，完整纠正后理解。`multiple agents` 在该语境中比 `multi agents` 更自然。

#### `The agent decides...`

教师在回答前直接给出：

> The agent decides what to do.

用户随后正确复述。该结果属于完整范句后的跟随表达，不能判断自然掌握。

#### `The agents decide...`

在轻微语义提示后说出：

> Multiple agents decide by themselves.

主谓匹配正确，属于轻微提示后成功。

综合判断：`agent lives` 已有无提示证据，`agents decide` 有轻微提示后成功证据；`agents live` 的自然产出仍不稳定；`agent decides` 本次测试被完整范句污染。单复数主语快速切换尚未自动化。

### `over the weekend` 与过去时

第一次自然回答：

> Over the weekend, I have been. dealing with a big and complicated document.

`over the weekend` 再次无提示成功，时间短语保持第 5 级。已经结束的周末事件中，时态仍自然回到不合适的完成进行时。

教师提供 `dealt with` 后，用户说出：

> Over the weekend, I dealt I dealt with a big and complicated document.

`dealt with` 属于完整提示后成功。一般过去时与已结束时间短语的搭配尚未自动化。

### showcase demo 核心表达

第一次提问：

> What kind of demo are you developing?

第一次回答：

> I developing a showcase demo.

在 `Try “We”` 提示后补充：

> Using a multi- Agents framework.

随后教师提供完整句，用户完成复述：

> We are developing a showcase demo using a multi-agent framework.

首次测试中可以自然恢复 `showcase demo`，完整句框架需要提示。

经过听力、结构训练和长暂停后，延迟提问：

> What does your showcase demo use?

用户无提示回答：

> Our showcase demo use a multi-agent framework.

`multi-agent framework` 已形成真实的较长时间后独立提取证据。第三人称单数仍丢失，目标形式为：

> Our showcase demo uses a multi-agent framework.

当前应区分两个层级：

- `multi-agent framework` 核心内容：第 5 级，延迟回忆成功。
- 完整句框架及 `demo uses`：第 3～4 级，能够自行组织，但语法尚未稳定。

### 第一轮 30 秒 GDC 自我介绍

用户实际表达：

> Hi, I’m Kara. I come- China. I work for Greena- The uh Game Innovation Department. We are developing a showcase demo using a multi agent framework and the the agent- uh Lives in a simulation town and decides what to do by themselves.

当时估计约 35 秒。整段没有从头重启，存在多次句内停顿和局部修正。

已覆盖：

- Kara
- Grina，公司名被转录为 `Greena`
- Game Innovation Department
- showcase demo
- multi-agent framework
- agent 在 simulation town 中生活并自主决定行为

未覆盖：

- `I’m a game producer.`
- AI-native games and applications
- 参加 GDC 的目的

主要表达问题：

- `I come- China.` 应稳定为 `I’m from China.` 或 `I come from China.`
- 公司与部门之间的结构没有完成，可使用 `I work for Grina in the Game Innovation Department.`
- 单数 agent 的 `lives` 和 `decides` 在本段中使用正确。

第二轮未执行。本次不能判断重构以后能否在 30 秒左右一次完成介绍。

### 41 词 GDC 风格听力

实际材料：

> First, our team tested an NPC memory system, but players felt disconnected. However, when we added small personal details, like daily routines, players started caring more and stayed longer. The key point is that tiny human details can change player engagement.

完整朗读两次。第一次回答记录完成前没有提供局部内容提示。

#### 第一次听后

用户能够保留：

- 主题与 NPC memory system 有关。
- 开发者进行了一项修改。
- 修改带来了体验方面的正向变化。

用户明确表示：

> I just remember the developer changed something… but I can’t remember the details.

未能恢复：

- `players felt disconnected`
- `small personal details`
- `daily routines`
- `players started caring more`
- `stayed longer`
- `tiny human details can change player engagement`

首听表现为主题和大方向得到保留，问题、具体修改、具体结果和结论基本丢失。

#### 第二次听后

能够恢复修改：

> The developer added some small details of the NPC.

将结果重新解释为：

> the NPCs are more like a living person

原文中的 `players started caring more and stayed longer` 仍未恢复。核心结论无法独立总结，教师完整提供结论后才建立理解。

困难来源：

1. 第一次输入后的具体信息保持。
2. 同时保存 problem、change、result 和 key point 四个槽位。
3. 根据听到的信息即时归纳结论。

本次未出现明确的核心词汇障碍。材料只有 41 词，结果仍显示明显的细节保持困难。由于材料长度不合规格，本次用于补充趋势证据，不用于替代 75～90 词标准测试。

### 演讲结构信号

- `First`：无额外提示成功，当前第 4 级。
- `However`：第一次未使用，经过多次直接提示后成功，维持第 3 级。
- `The key point is`：结构本身无额外提示成功，当前第 4 级；结论内容此前已由教师提供，不能据此评价听力保持。

总结中再次出现：

> players feels

目标形式为 `players feel`。复数主语与谓语原形的匹配继续列为高频自动化项目。

### `work for everyone` 跨场景测试

场景为三名 GDC 参会者在步行、出租车和 shuttle 之间选择交通方案。用户开始阶段没有听清情境；重新说明后仍未自然调用目标表达。提示逐步升级到完整句：

> We need a plan that works for everyone.

用户随后正确复现：

> I need a plan that works for everyone.

本次属于完整提示后成功，没有形成新场景自然迁移证据。该表达保留第 4 级历史状态，跨场景第 6 级仍未建立。

### 当次结论

- `multi-agent framework` 出现较长间隔后的独立恢复，是本次最明确的进步。
- `over the weekend` 再次无提示成功，短语本身已经稳定；过去时搭配仍需单独自动化。
- 第三人称和主谓数量匹配继续出现 `demo use`、`players feels`、`agents living`。
- 第一次听后的具体信息保持仍是当前最影响 GDC 听讲效果的能力。
- GDC 自我介绍可以连续完成约 35 秒，核心信息覆盖不足，第二轮压缩训练需要补做。

### 下次必须复测

1. 使用未提前暴露答案的新内容测试 `agent lives / agents live / agent decides / agents decide`。
2. 无提示测试 `Our showcase demo uses a multi-agent framework.`
3. 完成两轮 30 秒 GDC 自我介绍，第二轮必须在当次训练中执行。
4. 使用词数已经核验的标准听力材料，严格保存首听四个槽位。
5. 用简单、已确认听懂的新场景复测 `something that works for everyone`。
